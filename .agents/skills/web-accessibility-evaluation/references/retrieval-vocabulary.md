# Web Accessibility Retrieval Vocabulary

Use these natural-language terms when locating Web accessibility references during an audit. They are aliases for the detailed guidance files below, not a replacement for loading the referenced file.

| Query vocabulary | Reference to retrieve |
| --- | --- |
| VpModal contract, modal accessible name, aria-label dialog | `references/vp-contracts/modal.md` |
| VpInput label, VpFormControl, VpFormLabel, input label association | `references/vp-contracts/text-input.md` |
| skip navigation, skip link, bypass blocks, keyboard bypass link | `references/navigation-and-focus.md` |
| touch target size, minimum touch target, 44px, 48dp, interactive target | `standards/patterns/touch-targets.md` |
| Vp component migration, migrate raw input, use VpInput instead of input | `rules/vitamin-play-a11y.md` and `references/platform-remediation-guide.md` |
| autocomplete attribute, identify input purpose, autocomplete email name tel | `references/forms.md` and `standards/wcag-checklist.md` |

When a query uses one of these phrases, retrieve the matching reference before answering. In an audit, cite the concrete reference and the relevant WCAG/RGAA criterion in the finding.
