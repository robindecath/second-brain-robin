# Coverage Limitations & Blind Spots

> **Usage**: Include this section as a mandatory appendix in every audit report generated by any platform skill (web, iOS, Android). Copy verbatim and append platform-specific items from the table below.

---

## Mandatory Disclaimer (all platforms)

This audit was conducted via static code analysis. The following categories are
**systematically undetectable** from source code alone:

| Category                                    | Why static analysis cannot verify this          |
| ------------------------------------------- | ----------------------------------------------- |
| Color contrast ratios                       | Requires rendered pixels and computed styles    |
| Alt text _relevance_ (semantic check)       | Cannot judge whether alt matches image meaning  |
| Tab/focus order with CSS reordering         | Visual order is a rendering concern             |
| Keyboard activation of custom widgets       | Requires a real browser event loop              |
| Screen reader announcement quality          | Varies by AT + browser combination              |
| CMS/API-injected content                    | Values come from data, not code                 |
| `prefers-reduced-motion` compliance         | Animations only visible at runtime              |
| Third-party iframe titles                   | External to the source code                     |
| Link purpose out of context                 | Meaning depends on surrounding rendered content |
| Custom element internals (ElementInternals) | ARIA may be attached invisibly in markup        |
| Live region debounce timing                 | Behavior depends on update frequency at runtime |

Items marked `RUNTIME_REQUIRED` must be verified manually or with runtime tools
(axe-core, screen reader, keyboard navigation).

## Platform-Specific Additions

### Web

| Category                                  | Why                                                   |
| ----------------------------------------- | ----------------------------------------------------- |
| CSS `list-style: none` stripping semantics | Requires Safari rendering to confirm behavior         |
| `color-scheme` property interaction        | Requires dark mode rendering                          |
| Focus indicator visibility (`:focus-visible`) | Depends on browser heuristics and computed styles  |

### iOS

| Category                                    | Why                                                |
| ------------------------------------------- | -------------------------------------------------- |
| VoiceOver announcement phrasing             | Varies by iOS version and voice settings           |
| Gesture interactions (swipe, rotor)         | Requires physical device or simulator interaction  |
| Dynamic Type rendering at all sizes         | Layout depends on device screen and font scaling   |
| Switch Control navigation paths             | Depends on runtime focus group resolution          |

### Android

| Category                                    | Why                                                |
| ------------------------------------------- | -------------------------------------------------- |
| TalkBack announcement phrasing              | Varies by TalkBack version and device OEM          |
| Touch exploration gesture paths             | Requires physical device interaction               |
| Text scaling rendering at 200%              | Layout depends on device and density               |
| Switch Access scanning order                | Depends on runtime accessibility tree resolution   |
